## 介绍

MusicCardX 是 [MusicCard](https://github.com/iqonli/MusicCard) 的 Flutter 移植版，在 Android 上独立运行。原版的封面、背景、阴影、文字、歌词、颜色、字间距、输出倍率和样式配置均已移植，同时加入音频信息读取、在线搜索、字体管理、更多封面形状和 Android 分享接收等功能。

歌曲信息可以手动填写、从音频文件读取或在线搜索；封面可以从本地选择、从音频读取、在线搜索，也可以接收其他 APP 分享的图片。完成排版后，可以预览、保存、复制或分享卡片。

目前包含：

- 读取音频文件中的歌曲信息、歌词和内嵌封面
- 在线搜索封面和歌曲信息
- 五种背景模式、封面裁剪与平铺
- 十种封面形状、独立四角参数和阴影
- 八个独立的卡片文字元素
- 歌词排版、三段渐变分隔线和文字光晕
- HEX、自动黑白、彩虹色表达式和五个环境颜色
- Celebi、Wu、RGB 分桶、类 foobar 四种环境色算法
- 封面选点取色和油漆桶取色
- 本地字体管理、可变字体和 ezCD 字体库共享
- 卡片文字与歌词分别进行 OpenCC 简繁转换
- 样式配置库、JSON 导入导出
- PNG、JPG 图片输出及质量设置

## 安装与使用

从 [Releases](https://github.com/iqonli/MusicCardX/releases) 下载 APK 并安装。最低支持 Android 8.0（API 26）。大多数手机选择 `arm64-v8a`；`x86_64` 用于对应架构的设备和模拟器。

打开应用后，先在「输入」页面填写歌曲信息并选择封面，再到「工作台」调整样式。字体、配置、保存目录和图片格式可以在「设置」中管理。完成后，在顶栏预览、分享、复制或保存卡片。

预览随输出倍率缩放。图钉可以固定预览位置，关闭后预览随页面滚动。双指缩放和平移预览，单击进入大图页；大图页支持缩放、平移、双击放大或还原，以及适应屏幕和原始大小。

工作台使用表格编辑样式。点击表头可以批量修改整列，点击第一列可以单独编辑对应元素，点击其他单元格直接修改参数。

## 歌曲信息与封面

### 从音频文件读取

支持 MP3、FLAC、MP4、M4A、APE、OGG、Opus、WAV、WebM、MKV、AIF、AIFF、AIFC 和 MOV 等格式。

应用会读取音频文件实际提供的标题、艺术家、专辑、日期、Disc、Track、流派、语言等 Tag，并尝试读取歌词和内嵌封面。不同格式提供的字段有所不同；没有内嵌封面时，当前封面保持不变。

Android 的分享或打开菜单也可以把图片、音频、JSON 和文本交给 MusicCardX。应用会先显示待导入内容，确认后再更新当前封面或歌曲信息。

### 在线搜索封面

支持 163、Apple 和 Apple 不限速。

搜索框会带入当前标题、艺术家和专辑。预览尺寸默认 `150`，下载尺寸默认 `1000`，输入 `0` 可向源站请求最大尺寸。

点击候选封面进入大图页，右上角依次为下载、保存和 ✓：

- **下载**：按下载尺寸获取大图。
- **保存**：保存当前查看的图片。
- **✓**：获取大图后应用为当前封面。

封面原图按源文件字节保存，沿用卡片命名规则并追加 `-cover`。卡片导出的 PNG／JPG 和质量设置不会改变封面原图。

### 在线搜索

输入页的「在线搜索」分为三个 tab：

- **传统爬爬**：163、Apple、Apple 不限速和 QQ 音乐。标题、艺术家必填，专辑选填。
- **AI外包**：带入当前信息，生成可以编辑、复制的提示词，再把 AI 回答粘贴到「编辑歌曲信息JSON」。普通 JSON 和完整的 JSON 代码块都能识别。JSON 编辑器里的「确定」应用信息，顶栏 ✓ 返回。
- **来自音乐软件**：粘贴网易云、QQ、酷狗、酷我、波点或汽水的分享文本，也可以从音乐软件直接分享到 MusicCardX。支持的链接形式见[解析说明](docs/MUSIC_SHARE.md)。

搜索结果按标题、艺术家、专辑、完整日期、Disc、Disc 总数、Track 和 Track 总数分成八行，各行独立选择，列表整体横向滚动。传统搜索默认保留当前值；分享解析默认选中各项首个候选，最高分与原值相同时保持「最佳&保留」。

选择专辑后，日期和曲序候选对应到该专辑。右上角 ✓ 应用选择，底部显示各源状态和候选数量。候选按匹配程度和出现次数评分，重复记录合并计算。

传统搜索右上角的小地球可设置 Apple 目录地区，支持全球两字母代号（如 `cn`、`us`、`jp`、`gb`）。分享链接有封面时可以查看，先请求 150px 预览；下载和使用前填写尺寸，默认 1000，0 为最大。

网易云分享缺少音轨或碟片信息时，会再用传统搜索的网易云源补全：100分正常显示，80分至不足100分标为「存疑」并减淡色块，低于80分不采用。只补缺失字段，标记不写入歌曲JSON。缺少封面时也会搜索，只有100分结果可用。

「管理禁用项目」可禁用九项标准字段。禁用项显示「已禁用」，不进入歌曲信息 JSON；JSON、音频和在线结果导入时也会过滤。重新启用后从空白开始填写。「清空歌曲信息、封面与歌词」可一次清空当前输入。

歌曲 JSON 新增预留字段 `cover`，可保存图片 URL 或本地路径，暂不加载。

## 工作台与样式

### 输出倍率

固定倍率为 `1x`、`2x`、`3x` 和 `4x`，也可以输入 `0.1–10` 之间的自定义倍率，最多保留三位小数。

卡片基础高度为 `400 × 倍率`。宽度根据封面比例、歌词容器、文字宽度、光晕和水印动态计算，因此同一倍率下宽度可以不同。

### 背景

提供五种背景模式：

| 模式 | 绘制方式 |
| --- | --- |
| 融合 | 根据封面环境色和随机种子生成渐变及多个椭圆色块 |
| 墨点 | 使用固定色块并进行模糊处理 |
| 采点 | 使用固定色块，不进行模糊处理 |
| 模糊 | 截取封面并进行模糊 |
| 纯色 | 使用指定的固定颜色 |

融合背景支持输入、复制和刷新种子。同一 X 版本、同一封面、同一配置和同一种子可以复现背景。种子博览会每批生成 20 张预览图，点击使用种子，长按查看大图；只有融合模式显示该入口。

模糊背景可以调整强度和封面截取位置。截取位置为 `0–100%`，横向裁剪时对应左侧到右侧，纵向裁剪时对应顶部到底部。

### 封面

没有封面时，卡片不会绘制占位图，也不会保留封面、阴影或对应空白区域，文字会向左移动，卡片宽度随之变化。

非正方形封面支持两种处理方式：

- **裁剪**：按封面区域裁剪。
- **平铺**：保持原图宽高比，改变封面显示宽度，并重新计算文字位置和卡片宽度。

封面形状包括普通圆角、连续圆角、超椭圆、切角、内凹角、椭圆、椭圆圆角、二次曲线圆角、圆弧内凹角和独立四角。各类型的参数分别保存。封面阴影可以单独调整不透明度和深度。

### 卡片文字

卡片包含八个独立文字元素：

| 元素 | 内容 |
| --- | --- |
| Title | 标题标签 |
| Title 文本 | 标题内容 |
| Artist | 艺术家标签 |
| Artist 文本 | 艺术家内容 |
| Album | 专辑标签 |
| Album 第一行 | 专辑内容 |
| Album 第二行 | 日期、Disc 和 Track 等信息 |
| 水印 | 自定义水印 |

每个元素都可以分别设置字号、字体、字重、斜体、颜色、不透明度、模糊强度、模糊不透明度和字间距。文字可以填写普通文本，也可以使用标题格式化表达式。

卡片文字支持顶部、中间和底部对齐。表格点表头可批量修改一列，点第一列则进入该元素的详细样式。

### 歌词

歌词默认关闭，开启后显示在封面左侧，并推动封面和右侧文字整体向右移动。

歌词容器宽度可以固定，也可以根据最长一行自动计算。支持多行内容、字号、字体、字重、斜体、颜色、不透明度、光晕、字间距、上间距、下间距、行距，以及左中右、上中下对齐。

歌词与封面之间可以加入分隔线，分别设置粗细、四周间距、顶部／中间／底部颜色和不透明度，形成三段渐变。

## 颜色与取色

普通颜色使用六位 HEX，可以省略 `#`。输入会统一为小写。

`black` 和 `#black` 表示 `RGB(18,18,18)`，`white` 和 `#white` 表示 `RGB(250,250,250)`。自动黑白模式可以自动判断，也可以锁定为黑色或白色。

环境色算法提供四种选择：

- `Celebi`
- `Wu`
- `RGB 分桶`
- `类 foobar`

应用会从封面提取五个环境颜色，用于背景、自动黑白和彩虹色。也可以开启自定义环境颜色，手动修改五个颜色。

封面选点页面会显示十个典型颜色标记，可以拖动标记重新取色，连续选择五个颜色后写入环境色。取色支持局部平均和油漆桶模式；油漆桶使用四连通区域查找相近颜色。选点使用长边 512 像素的采样图，取色边长指采样图中的像素。

### 彩虹色表达式

彩虹色根据基础色和目标色进行 RGB 插值，格式为：

```text
rainbow%n+hex
```

也可以简写为：

```text
r%n+hex
```

其中 `n` 为 `0–100` 之间的百分比，`hex` 是可选的基础 HEX 颜色。省略基础色时，使用当前自动近黑或近白。

计算方式为：`n%` 的基础色加上 `(100-n)%` 的目标色。

例如：

```text
rainbow%20
rainbow%20+#114514
r%20
r%20+114514
```

## 字体管理

字体管理器支持 TTF、OTF、TTC、OTC 和 ZIP 字体包。导入后按家族和字重分组，可以筛选、预览、查看字体信息和删除字体。

静态字体按家族中实际存在的字重匹配；支持相应轴的可变字体可以调整 `wght`、`ital` 和 `slnt` 等轴。卡片正文使用选中的实际字重，粗体优先匹配同家族的 700 字重，斜体优先匹配对应字面。

字体有两种来源：

- **导入字体**：字体由 MusicCardX 管理，文件保存在应用自己的字体目录。
- **依赖于 ezCD**：读取用户授权目录中的 `ezcd-fonts.json`，校验清单和文件哈希后使用。

ezCD 字体共享协议见[接入说明](docs/ezCD-font-sharing-v1.md)。

应用界面字体与卡片输出字体相互独立。设置中的显示字体只改变应用界面；卡片字体需要在工作台中分别设置。

## 标题格式化与简繁转换

八个卡片文字元素和歌词都可以使用标题格式化表达式。字段名不区分大小写，支持字段、条件括号、嵌套函数、变量、数学、字符串和日期等常用语法。

默认标题内容使用 `%title%`、`%artist%`、`%album%` 等字段。默认的 Artist 内容会在艺术家为空时回退到专辑艺术家。Album 第二行可以显示年份、Disc 和 Track 信息。

`%datey%` 是 MusicCardX 保留的自定义字段，只读取 `%date%` 的前四位。文件名规则还支持 `%seed%`，仅在融合背景模式下有值。

标题格式化函数和语法范围见[标题格式说明](docs/TITLE_FORMATTING.md)。MusicCardX 实现了常用函数，语法范围与完整 foobar2000 标题格式化引擎并不完全相同；本地输入没有提供的播放器字段也无法自动读取。

卡片文字和歌词分别设置 OpenCC 转换，支持：

1. `关闭`：保留原文。
2. `t2s`：繁体转简体。
3. `s2t`：简体转传统汉字。
4. `s2twp`：简体转台湾繁体及常用词。
5. `s2hk`：简体转香港繁体。

转换发生在标题格式化表达式求值之后，只改变最终显示文字，不修改歌曲信息和歌词原文。OpenCC 词典已内置。

## 配置文件与图片输出

应用会自动保存当前编辑状态。样式配置库支持保存、复制、重命名和删除；配置可以导入、导出为 JSON。

配置包含输出倍率、背景、封面形状、颜色、八个文字元素、歌词、OpenCC 模式、字体偏好和在线搜索设置。字体文件、封面图片字节和系统目录授权分别管理。完整字段范围见[配置覆盖清单](docs/CONFIGURATION.md)。

图片默认保存为 PNG，也可以选择 JPG 并设置 `1–100` 的质量，默认 95。压缩设置作用于卡片的保存、复制和分享，不作用于预览，也不作用于封面原图。

默认文件名规则：

```text
MusicCardX-[%title%-][%artist%-][%album%-][%seed%]
```

`%seed%` 仅在融合模式下有值。文件名设置时实时预览；遇到同名文件会自动追加时间戳。

单张图片建议不超过 1 亿像素，单边最长 32768 像素。超过任一数值时会弹窗警告，可以取消或继续生成；继续生成可能占用大量内存。

## 一些~~bug~~特性！新手必看#1

### 好看的背景要自己刷

**融合背景模式是根据封面环境色和随机种子生成多个融合色块，所以背景好不好看全靠种子，种子要自己刷。**

X 增加了种子博览会，可以一次看一批随机种子，点击使用，长按查看大图。

### 为什么默认配置这么丑

**图片仅供参考，请以实物为准。哈哈哈哈哈哈哈哈我才不会把我的配置发出来。**

### 模糊就是发光

如果你要做字体发光，把文字的`模糊强度`改成 4，`模糊不透明度`改成 160–200。

## 一些~~bug~~特性！新手必看#2

### 无封面时不保留封面位置

没有读取到封面时，卡片不会显示占位图，也不会保留封面、阴影或对应空白区域，文字会向左移动，整张卡片也会变窄。

### “平铺”不是重复铺砖

`平铺`模式不会重复排列同一张图片。它固定封面显示高度，并按照原图宽高比改变封面宽度，随后重新计算文字位置和卡片总宽度。

### 卡片宽度不是固定值

同一输出倍率下，图片高度由 `400 × 倍率` 决定，宽度会根据歌词容器、分隔线、封面宽高比、标签列宽、文字宽度、光晕和水印动态计算。`2x` 表示尺寸倍率，不代表固定分辨率。

### 空字间距和 0 字间距完全不同

字间距留空时，程序把整段文字交给字体原生排版，保留字体自身的字符定位、kerning 和连字。输入任何数值时，包括 `0` 和负数，都会改为逐字绘制。`0` 表示不额外增加距离，并不等于原生排版。

### 显示字体和生图字体相互独立

应用设置中的显示字体只改变 MusicCardX 界面，不改变导出图片中的 Title、Artist、Album、歌词或水印字体。卡片文字和歌词需要分别设置字体。

## 自行编译

当前工程使用 Flutter 3.47.9、Dart 3.13.7、JDK 21、Android SDK 36、BuildTools 36.0.0 和 NDK 28.2.13676358。依赖版本以 `pubspec.lock` 为准。

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

Release 构建可在 `android/signing.properties` 中配置签名，并放入对应密钥。官方 APK 使用 `iqonli-1` 签名；自行签名的 APK 使用对应密钥安装。
