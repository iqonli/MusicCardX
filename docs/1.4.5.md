# MusicCardX1.4.5

“来自音乐软件”解析网易云链接后，如果Disc、Disc总数、Track或Track总数有缺失，使用“传统爬爬”的网易云源搜索并读取详情，只补缺失项。四个字段从同一条匹配记录取得，不覆盖原解析值，不拼接不同专辑的数据。

匹配100分正常显示；80分至不足100分的补全值在气泡中标注“存疑”，背景色减淡；低于80分不采用。“存疑”属于界面提示，应用后仍保存原数字字符串，不进入歌曲JSON。搜索异常保留直接解析结果。

网易云链接没有解析出封面时，调用在线搜索封面的网易云源，仅采用100分且封面链接非空的结果，才显示“查看封面”。已有封面保持不变。其他音乐平台的分享解析不增加此补全流程。

原构建版本1.4.5+21，ARM64和x86_64分别使用versionCode2021和4021，沿用iqonli-1签名。包含自动化分数边界、取消、异常及界面应用测试；尚未真机测试。

联网验证样例：网易云歌曲2091914322的直接解析只有标题、艺术家和专辑，搜索补入100分的Disc1、Track2，总数没有可靠值则留空。以同一组歌曲信息调用网易云封面搜索，返回100分且带封面链接的候选；按钮的100分门槛另由界面测试验证。测试响应及计算分数保存在docs/validation/1.4.5。


本次修订：版本名仍为1.4.5，内部版本号升至1.4.5+22；单张输出建议上限提高至1亿像素，单边提高至32768像素。超过任一建议上限时，渲染前弹窗提示，用户可取消或确认继续；不自动缩小输出。ARM64和x86_64分别使用versionCode2022和4022。
