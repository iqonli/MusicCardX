# MusicCardX 1.1.0

- 底栏改为“输入／工作台”两个入口，导出／分享移到顶栏。
- 工作台使用 32px 行高的横向文字样式表。背景、封面、歌词、分隔线、颜色等分区独立横向滚动，每行最多三个紧凑控件。表格点单元格直接编辑。
- 预览上方新增图钉，默认开启并保存选择。开启时预览独立固定；关闭时预览加入页面滚动。
- 大图预览按完整窗口建立缩放视口，初始适配屏幕，支持缩放、平移和横竖屏。
- 删除 Kotlin 字体管理器、选择器、字体解析和 Typeface 实现。界面、SFNT 名称／字重／可变轴解析、TTC 面提取、字体注册和索引均为 Flutter／Dart。
- 字体来源二选一：“导入字体”管理 X 自己的应用内字体；“依赖于 ezCD”只读已授权外部库。切换来源不会删除另一来源的字体。
- 本地支持 TTF、OTF、TTC、OTC、ZIP 导入，按家族和字重分组，筛选、预览文字、72／80／88／96 与自定义字号、多选删除、字体选择。
- 自动尝试迁移 1.0.0 的字体索引和可访问原文件；不可访问项需要重新导入。保留匹配成功的原字体 ID，避免配置失联。
- ezCD 模式按接入文档 v1 使用 ezcd-fonts.json，SAF 授权由用户单独授予 X。按显示名逐级查找，不拼接内容 URI；校验路径、版本、状态与 SHA-256，TTC 使用 faceIndex。缓存只写 X 自己的目录。retired 清空共享快照；读取失败保留上次可用快照。打开／恢复前台及手动刷新会重读清单。

Android 宿主只保留系统选择器、SAF 和普通文件传输等平台接口；没有字体业务 Kotlin 代码。Flutter 无法直接调用 Android 的 SAF，因此这层系统访问仍通过平台通道完成。
