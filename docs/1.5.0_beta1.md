# MusicCardX1.5.0_beta1

本版以1.5.0相同输入的像素结果为基准，不降660px工作网格，不删噪声层数，不改变种子映射、实验参数范围、颜色公式或缩放方式。

- 预计算固定颜色的OKLab值、雾化锚点、色场宽度和融合hard的固定混合颜色。
- 复用Perlin格点的梯度向量；每次生成重置缓存，不近似噪声。
- 背景RGBA结果最多缓存12项，按模式、种子、五色、画布宽度及雾化封面对象区分；相同背景的并行请求复用同一任务。
- 雾化封面缩放与半径7/20模糊单独缓存，更换封面自动失效。改变背景模糊强度继续使用原Flutter模糊路径。
- 编辑器退出清理背景缓存。所有缓存仅在内存，不写文件。

## 验证

测试文件test/beta150_test.dart及原版参考实现随源码提供。比较完整RGBA及完整卡片PNG，使用严格字节相等断言而非近似误差阈值。覆盖四算法、多种种子、黑白/灰阶/彩色调色板、横竖比例、有无封面、缓存命中与失效和输出倍率。48组完整背景RGBA及24组完整卡片PNG对照通过（0.2×/0.5×/1×/2×）。测试通过代表这些已测输入一致，不能代替所有设备的验证。

Linux原生AOT单次生成实测，旧版→优化版：融合soft872→634ms、融合hard861→443ms、流光217→170ms、带512px封面的雾化909→597ms。手机未实测，不承诺首次生成达到200ms。缓存命中可跳过背景重算，完整卡片仍需要排版和合成。

未采用降分辨率或GPU shader，因为本版优先要求保持像素结果。
