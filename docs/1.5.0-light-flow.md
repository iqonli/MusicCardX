# 1.5.0流光测试版

仅流光改用FlowBench4-Screen-v4-Termux中gradientFlowV2的丝带公式；使用原warp_strength 0–1.2、ridge_strength 0–0.72、ridge_frequency 2–10范围，通过当前X种子规则采样。代码标识仍为lightFlow，显示名为流光 (测试版)。其他背景算法未修改。

v4的V2引擎：双重正弦丝带、独立条纹频率、exp(-14*slosh²)、色雾与丝带高光。v4也保留Near分支，微纹上限0.06。v5/V7改用V5分支，微高光上限降到0.015，新增宽度与对比度；v7进一步按种子采样。上传的独立v7代码包与完整v7测试包的流光V5函数相同。

本次采用v4 V2，而非v4 Near或v5/V7 V5。公式来自测试包，公共数学仍使用X原生模块的double实现，工作网格与后期模糊不变。v7流光代码已归档到archive/light-flow-v7-beta2。

显示名：融合经典版、融合新版-soft、融合新版-hard、流光 (测试版)。配置内部ID不改，无需迁移配置。

版本1.5.0+35。按用户要求不执行像素一致性或回归验证，直接构建Android两个架构。
