# MusicCardX1.5.0

基于1.4.8源码修改，不包含APK、签名密钥或本机构建缓存。

- 背景顺序：融合classic、融合soft、融合hard、流光、雾化、墨点、采点、模糊、纯色。
- 四种新背景使用Dart重写，采用上传实验包v7的噪声、OKLab/HSV混色、纹理预模糊与五参数公式。融合hard沿用实验包v6非周期色场与旧公式混合。
- 每项参数保持实验筛选范围，UTF-8 FNV种子哈希与32位混合规则不变。种子参数命名空间中的模式名同步改名，因此同种子不保证与实验工具逐像素一致。保留X当前环境色来源，不替换用户选定的取色算法。
- 660px最长边工作网格在后台isolate计算，Flutter高质量bicubic重建，叠加各背景独立的模糊强度。雾化的封面纹理使用512px封面及半径7/20的双向box blur。
- 新增backgroundBlurStrengths映射，旧fusion迁移为fusionClassic；旧模糊值迁移到当前模式。配置仍保留blurStrength用于当前模式及旧格式兼容。
- 纯色自定义使用原高级HEX/彩虹色表达式输入框；输出渲染沿用彩虹色解析。
- 样式配置三行重新排列；来自音乐软件封面入口加入红字；提示词放大按钮贴边透明悬浮，尺寸缩小到上一版70%。

## 校验

独立Dart分析通过；与原C++公式比较100个RGB采样点，通道最大绝对误差0.0000024；800组种子参数范围检查及四种RGBA输出路径通过。尚未运行完整Flutter测试或Android实机验证。

回归测试：flutter test test/background150_test.dart

## 参数范围

|模式|五参数范围（按seedParameters顺序）|
|---|---|
|雾化|纹理0–0.10；形变0–0.20；色场0.50–0.75；细节抑制0–1；柔度0.55–1.45|
|融合soft|旧新混合0–0.80；频率3–7；光波0–0.50；旋涡0–1；颜色约束0–0.80|
|融合hard|旧新混合0–1；非周期形变0–0.48；过渡0.60–1.40；第四色0–1；云场混合0–1|
|流光|流动0.85–1.15；微纹0–0.015；第五色0–0.165；纹宽0.5–1.5；纹亮0.5–1.5|
