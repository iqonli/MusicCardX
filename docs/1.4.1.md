# MusicCardX1.4.1

版本1.4.1+15，继续使用iqonli-1签名。

- 搜索页标题、艺术家、专辑输入框之间增加16dp间距。
- 搜索源选项上方增加“分数低于 [20] 时不自动加载图片”。默认20，支持0—100，低于阈值只显示候选信息和下载预览按钮。点击按钮后才加载预览；等于阈值自动加载。阈值随应用状态和配置保存，旧配置默认20。调整阈值不清除已经加载的图片。
- 当前搜索页图片字节缓存上限调整为80MiB，按访问顺序淘汰。离开整个搜索页面清空缓存并取消请求；查看页自身的图像和Flutter解码图片缓存另有生命周期，不表示整个APP进程内存上限80MB。用户保存的图片不自动删除。
- 编辑歌曲信息JSON与清空歌曲信息同行，选择图片与在线搜索封面同行。封面尺寸长文案可在按钮内换行。
- 恢复源名称Apple不限速；候选163按实际成功路线显示163 EAPI、163 WEAPI、163 Legacy。Apple与Apple不限速候选显示地区代码。移除原名称分隔中的中点，使用空格。
- 修复启动时字体初始化与首次预览竞态：先完整读取字体管理器索引、刷新共享目录及加载界面字体，再开始封面和预览渲染。并行初始化请求共用同一个Future，不会因root目录已经赋值而提前认为索引已就绪。渲染仍等待各文字的真实字体解析与注册。
- 保留1.4.0行为：✓先下载指定尺寸大图，成功后才应用；下载失败不应用小图。保存按钮只保存当前版本。

最终测试、静态检查、双架构构建、版本和签名核验日志在docs/validation/1.4.1。未进行Android真机测试。

## 同版本修订（构建号+16）

底部SnackBar消息展示时间统一为1.5秒。保存封面直接写入当前图片的原始字节，依据文件头选择后缀和MIME，保留原格式、元数据及动图帧，不经过PNG/JPG编码器。本地选择的封面直接读取源文件；在线封面不再进行本地缩放重编码。下载尺寸仍通过源站请求指定，实际尺寸由源站返回。图片压缩设置只影响生成卡片的保存、复制和分享。版本名保持1.4.1，内部构建号递增以便覆盖安装。
