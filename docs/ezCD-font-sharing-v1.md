# ezCD 字体共享接入 v1

适用：ezCD 1.0.20+。在字体管理中选择“选择目录”后，**该目录根部的 `ezcd-fonts.json`** 是唯一发现入口。字体仍放在 ezCD 管理的子目录，不要扫描或猜测子目录名。旧版外部字体会在升级后启动 ezCD／打开字体管理时生成清单，不移动原文件。

## 读取约定

1. 让用户在你的 APP 中选择**包含清单的目录**，通过 SAF 保留读取授权。ezCD 的授权不能转给你的 APP；已有合法文件路径读取权限也可直接读取。
2. 以 UTF-8 读取清单，限制在 8 MiB 内。检查 `format == "ezcd-font-catalog"`、整数 `version == 1`。未知版本先不使用；忽略不认识的可选字段。
3. `status == "active"` 时读取 `fonts`；`retired` 表示该目录已停用，清单为空。不要继续用它的旧记录。
4. 每行的 `path` 相对**清单所在目录**；当前固定为两段 `子目录/文件名`。拒绝绝对路径、反斜杠、空段、`.`、`..` 和控制字符；文件路径读取还应检查规范化后仍在授权目录内。SAF 按 `COLUMN_DISPLAY_NAME` 逐级查询，并用 `buildDocumentUriUsingTree` 构建 URI，**不要把 path 拼进 content URI**。
5. 按 `faceIndex` 加载字体，TTC／OTC 的多行可能共用同一个文件。建议按 `sha256` 复制一份到自己缓存、核对文件哈希，再构建 Typeface；使用 `sha256:faceIndex` 区分字体面。缓存是消费者自己的副本，不改共享目录。

## 字段

| 位置 | 字段 | 含义 |
| --- | --- | --- |
| 根 | `format`, `version` | 上述协议名、版本号 |
| 根 | `writerId` | ezCD 安装的随机标识；一个目录只能有一个写入方 |
| 根 | `revision` | 不透明的内容版本标识，只作相等比较，不自行重算 |
| 根 | `updatedAt` | 最近一次内容发布的 Unix 毫秒时间；不代表心跳 |
| 根 | `status`, `fonts` | `active`／`retired`；字体面数组 |
| 字体面 | `id` | 稳定字体面标识，不要用名称当唯一键 |
| 字体面 | `path`, `sha256`, `size` | 相对路径、小写 SHA-256、字节数；不明大小时 size 为 null |
| 字体面 | `fileName` | 原始导入文件名，仅供显示，不能拿来定位文件 |
| 字体面 | `faceIndex` | 字体集合中的面索引，从 0 开始 |
| 字体面 | `fullName`, `family`, `familyKey`, `subfamily` | 全名、家族、分组键、子家族 |
| 字体面 | `weight`, `italic` | ezCD 识别的字重 1–1000、斜体布尔值 |
| 字体面 | `axes` | 可变轴数组，每轴含 `tag`, `min`, `default`, `max`；静态字体为空 |

已有本地缓存文件时，加载核心代码：

```kotlin
val row = catalog.getJSONArray("fonts").getJSONObject(index)
val typeface = Typeface.Builder(verifiedCacheFile)
    .setTtcIndex(row.getInt("faceIndex"))
    .build()
```

可变轴需按 axes 的范围设置 `setFontVariationSettings`；静态字体通过同家族的其他字体面匹配字重，不会自动插值。

## 更新与失败

在你的 APP 打开／恢复前台、用户手动刷新时重新读取，比较 revision；目录监听可辅助，不能依赖所有 SAF 提供者都发送通知。重新读取成功后，以整份 fonts 替换旧快照；已删除、停用或不可访问的选择应回退到系统字体。

导入、重复导入恢复字体面、删除和迁移均更新清单；ZIP／多文件导入在批次结束后发布，中断后按已提交记录补发。切换外部目录／转内部／转仅原文件时，旧清单标为 retired；选择“保留”只保留旧字体字节，不保留字体记录。路径只在当前快照中有效，不能永久缓存。迁移到另一目录后，消费者需重新选择新目录，授权不会自动转移。

普通文件系统使用原子替换；**SAF 不保证原子替换**。读取遇到空文件、不完整 JSON、授权失效、文件不存在或哈希不符时，稍后重读，暂保留上次可用快照与自己的缓存，避免读到一半就清空界面。ezCD 会记录待同步操作并重试，清单更新成功前保留待删除文件。消费者必须只读，不编辑／删除清单或字体文件。

只共享“选择目录”模式；“应用内部”“仅原文件”不对外生成活动清单。清单不包含 ezCD 私有数据库路径或可直接转授的 URI。共享存储不改变字体文件自身的使用许可。
