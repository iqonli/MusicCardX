# MusicCardX 1.3.0

包名com.iqonli.musiccardx，versionCode 4，继续使用iqonli-1签名。源代码中不包含签名私钥和密码。

## 界面与输入

- 清理界面文案中汉字与ASCII之间的多余空格。全局背景和顶栏为白色，禁用滚动后顶栏的着色和阴影变化。
- 设置新增monet开关，默认关闭，关闭时使用Flutter蓝色配色；开启时读取系统动态色，不可用时回退蓝色。
- 表格除内容上限200、字体上限180外，其他列按实际内容及表头测宽，不设人为上下限。单元格间距仍保留。
- 开、关状态统一用主题色，开加粗。歌词内容按钮显示行数；歌词排版、分隔线标题同时显示开/关和展开箭头，展开/折叠控制启用。
- 数值输入弹出后自动聚焦、全选，使用支持小数和负号的数字键盘。歌曲信息区域点击空白可取消输入焦点。
- 歌曲信息末尾新增编辑歌曲信息JSON弹窗，等宽文本框可滚动；复制整个JSON，粘贴先清空，确认时验证对象格式。省略的常规字段补为空值，保留额外标签字段。

## 种子博览会与图片查看

Copy seed右侧新增博览会。每批生成20个随机种子，一行一图；滑动到底继续生成下一批，也可点击加载。点击应用种子，长按按当前输出倍率重新生成大图。缓存使用缩略图，离开页面释放已生成图片。

随机序列改为原JS的UTF-16字符串哈希、32位混合、LCG。融合背景对齐随机数调用顺序、角度取整、椭圆数量、色号、透明度、大小和位置。Flutter与GDI+模糊、渐变仍有差异，不保证逐像素一致。旧种子在新算法下的构图会改变。

普通预览直接支持双指缩放、双击缩放和移动，使用PhotoView；长按保留独立大图入口，大图同样使用PhotoView。

## 环境色与选点

- 自动环境色默认Celebi，可在算法弹窗比较Celebi、Wu、RGB分桶各自的五色，然后选择。算法取色的调色板会供背景、自动黑白和自定义彩虹色共用。
- 打开自定义环境色时复制当前封面按所选算法得到的五色，五个色块放下一行。关闭后清空，再次开启重新提取。
- 开启自定义环境色后显示选点入口。封面页面生成10个典型色标签，支持缩放、点选、拖动；默认3像素边长局部平均。开始连续选取5个后，依次点五个不同标签，可以继续拖动，右上角确认写回五个环境色。
- 油漆桶模式默认关。启用后，以标签局部平均色为参考，通过四连通洪水查找邻接相近颜色，计算连通区域平均色，再与局部平均色等比例混合。自动标签和拖动后的标签都会刷新。为限制手机端开销，选点/洪水在长边512像素的采样图上运行，边长单位是该采样图的像素，不是原图像素。
- 自动黑白色改为自动、锁黑、锁白三态。自动仍使用原灰度阈值0.5，黑色#121212、白色#FAFAFA。
- 自定义彩虹色保留五个环境色选项，恢复独立自定义颜色按钮。
- HEX项目使用普通文本输入，保留原JS的自动黑白和rainbow/r%表达式提示。底部插入按钮打开颜色选择器，在光标/选区处插入；前面已有#时不重复插入#。环境色和彩虹色的直接颜色按钮使用颜色选择器。
- 取色封面边长输入框新增测试按钮：默认10点，最小20、最大1000；按均匀边长采样，逐点记录实际色相提取时间ms，不计入自动环境色量化开销。

## 字体与排版

加粗入口改为字重。可变字体按wght轴范围显示数值、−100/+100和滑条；静态字体提供同家族可用字重下拉框，显示子家族名。系统字体提供100至900字重。选择新字体时同步其实际字重，旧bold字段仍可导入。

设置新增文本对齐模式：左上角、中、右下角，默认中。按同一排的高度，对不同字号文字分别顶部、中轴、底部对齐。该设置作用于卡片信息排版；歌词仍使用自己的对齐设置。

封面新增普通圆角、连续圆角、超椭圆、切角、内凹角、椭圆和独立四角；参数按类型分别保留。裁切和阴影共用同一轮廓。

简繁名称按原JS实际值显示：关闭、t2s、s2t、s2twp、s2hk。原JS会将s2tw迁移为s2twp，因此这里显示s2twp。

## 外部分享与打开

注册图片和JSON/文本的SEND、VIEW入口，标签分别为替换当前封面、替换当前歌曲信息。收到后由应用再次确认才应用。图片拷贝到内部封面目录；JSON可为直接标签对象或带fields的对象；文本可为JSON、key=value/key:value行，纯文本作为title。既有保存图片目录不随歌曲信息替换。

## 标题格式范围

实现本地Title Formatting解析：字段、条件方括号、引号、转义单引号、注释、嵌套函数、惰性条件、多值标签、变量、数学、字符串、日期、路径函数。已覆盖原版默认表达式及本项目回归样例。与foobar宿主绑定的播放状态、数据库字段不会自动产生，须由输入提供。当前没有嵌入foobar2000 SDK，也未证明覆盖其全部函数；未知函数明确报错，不静默按普通文字输出。

详见docs/TITLE_FORMATTING.md中的实际函数清单和限制。
