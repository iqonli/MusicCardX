# MusicCardX1.3.1

包名com.iqonli.musiccardx，版本1.3.1+6。继续使用iqonli-1签名，可覆盖安装1.3.0。

## 编辑界面

- 文本对齐模式为顶部、中、底部，图标紧邻对应文字，默认中。
- 表格改用显式测量的Table布局，按当前界面字体、字重和系统文字缩放测量表头与内容，测量与绘制共用同一文本样式，避免继承字间距后意外截断。内容列最大200dp，字体列最大180dp，两者无内容宽度下限；其他所有列，包括元素列，都按内容自然宽度，无最小值和最大值。每格仅额外保留左右各6dp留白。表头点击批量编辑列，第一列点击编辑项目，开/关统一使用主题色。
- 选择算法弹窗为名称列预留相同宽度，五个色块的起止位置和宽度在各算法行完全对齐。
- 封面圆角改为弹窗，类型名称前使用对应路径的小图标。修复各类型半径已经保存却没有被渲染器使用的问题。
- 封面第一行选择图片，第二行保存封面、移除封面。三个按钮均无图标，移除前弹窗确认。
- 清空歌曲信息位于歌曲信息最下方，清空歌词内容位于歌词内容最下方。两者独立操作、无图标。
- 底部输入、工作台、设置仅显示文字。
- 配置库增加重命名和复制，按编辑、复制、删除顺序排列；保存当前配置使用保存图标。复制自动生成不冲突的副本名称。

## 封面选点

- 内部色点从34dp缩为25.5dp，即原来的0.75倍，普通状态不显示编号。
- 外围圆半径为内部色点半径的2倍，以当前颜色70%不透明度绘制；51dp直径圆覆盖的区域均可拖动取色。
- 开始连续选取5个移至顶栏；选满5个不同标注后才显示确认按钮。
- 选取顺序1—5显示在色点上方。移除当前颜色文字以及底部五个连续色块。
- 继续保留拖动重新取色、双指缩放封面、取色边长和油漆桶模式。

## 音频与外部导入

- 输入页封面区域下增加从音频文件读取，使用Flutter文件管理器单选文件。使用纯Dart读取元数据，不使用Android媒体元数据解析器。
- 读取标题、艺术家、专辑艺术家、专辑、日期、Disc/Track及总数、流派、语言，并读取歌词和内嵌封面。无内嵌封面时保留当前封面。
- 支持库识别的MP3、FLAC、M4A/MP4、APE、OGG、Opus、WAV、WebM/Matroska、AIFF/AIFC等格式；每个格式能提供的Tag取决于文件本身及格式能力。
- Android接收audio/*和application/ogg、application/x-ogg的分享与打开，入口文案为替换当前歌曲信息，应用前二次确认。没有注册所有未知二进制文件。
- 外部图片替换确认弹窗展示将要导入的新封面。
- JSON字段键名修剪并小写；移除空键、空字符串、null、布尔值、对象、无有效项的列表，有限数值转换为Tag字符串，列表移除无效项。有效的额外Tag保留。JSON编辑器粘贴合法对象后自动标准化、两空格缩进；语法错误保持可见，须修正后才能确认。
- 配置JSON只保留已知配置键和正确值类型，修剪无效值后补齐必要默认设置；不覆盖原始导入文件。

音频库基于audio_metadata_reader1.8.1，MIT许可证。源码内附本地兼容补丁：MP3的TPE1/TPE2分别对应艺术家/专辑艺术家，保留完整日期和标准USLT歌词；MP4支持aART；Vorbis兼容n/total；WAV优先UTF-8解码后回退Latin-1。详见third_party/audio_metadata_reader/MCX-PATCHES.md。

## 渲染与预览

- 修复默认Album第二行被简化拼接代码截走的问题，默认表达式和自定义表达式统一经过标题格式解析器。年份与Disc/Track同时存在时保留原表达式的“ · ”。
- 修复条件表达式的字段存在标记传播，使条件包裹的可选段正常显示。
- 对照原版MusicCard.js的WATERMARK_STRING_FORMAT，水印在右侧信息区左对齐，文字底部对齐封面底部，不再受文本行对齐模式额外偏移。
- 外部预览单击进入大图。双指都在图内时，同向移动平移，改变两指距离缩放；同一帧合并两指位置变化，避免平移被误算为缩放。单指手势留给页面滚动。
- 字体默认预览文本为“中国智造，慧及全球 MusicCardX 0123456789”。旧的默认文本自动替换，用户编辑过的文本继续保留并保存。
- 字体预览提供纯黑字白底、纯白字黑底两组。可变字体直接调整字重滑块、±100按钮和输入框；静态字体退化为家族中可用字重的下拉框，调整后实际重新匹配和加载字体。


## 接收流程补修（内部构建号+6）

- 外部分享改为顺序队列，确认弹窗打开时收到的新内容不会覆盖前一份。取消或处理失败后继续下一项。
- Flutter接收端持续读取队列，避免确认期间的通知被忽略后必须重新打开应用才能处理。
- 外部图片副本改用独立UUID文件名，避免短时间连续分享图片时文件名重复。
- 传入Intent未给出MIME类型时，从共享文件URI查询类型。
- 增加连续分享、失败后继续、外部封面预览和移除封面取消/确认的界面回归检查。

## 验证与边界

Flutter静态检查、单元与界面测试、两种ABI的Release构建及APK签名检查记录见docs/validation/1.3.1。

音频样本为自行生成的短音频，覆盖MP3、FLAC、M4A、OGG、Opus、WAV、内嵌封面、扩展歌词和标准USLT。它们不代表任意损坏文件或所有Tag变种都已验证。

没有进行Android真机运行测试。外部分享/打开、系统图片选择器和文件访问权限仍需用户在自己的系统上实测。标题格式仍是独立实现，未声称与foobar2000全部函数等价。选点仍使用长边512像素的工作图，边长单位和1.3.0相同。
