# 音乐软件分享解析

MusicCardX1.4.4的解析器用Dart和`dart:io HttpClient`运行，不依赖Python、Go、本地服务器或账号登录。实现依据用户提供的MusicShare Flutter实验包v7，另核对了当前酷狗桌面分享页。

## 支持链接

| 平台 | 形式与示例 |
| --- | --- |
| 网易云音乐 | `https://music.163.com/song?id=2091914322`，`163cn.tv`和`163cn.link`短链 |
| QQ音乐 | `https://y.qq.com/n/ryqq/songDetail/00265Jxe3JzXOJ`，`c6.y.qq.com`短链，带songmid或songid的官方链接 |
| 酷狗音乐 | `m.kugou.com/share/song.html?chain=分享码`，`www.kugou.com/share/分享码.html`，`t1.kugou.com`短链，带hash的官方歌曲页 |
| 酷我音乐 | `https://m.kuwo.cn/yinyue/56102277`，`www.kuwo.cn/play_detail/歌曲ID` |
| 波点音乐 | `h5app.kuwo.cn/m/bodian/playMusic.html?musicId=歌曲ID`；`play.html?mvId=视频ID`按MV处理 |
| 汽水音乐 | `qishui.douyin.com/s/短链`，`music.douyin.com/qishui/share/track?track_id=歌曲ID` |

可以输入整段分享文案、Markdown链接或多个链接。酷狗裸数字分享码不能唯一确认歌曲，程序不猜测其含义。波点MV可能有地区限制，返回视频信息时不会假造专辑和曲序。

## 候选与封面

解析结果沿用八行气泡流、查重和评分；有明确平台和歌曲身份的响应按直接匹配计分。只有分享文案、尚未核验身份的标题降为25分并明确标注。多条链接分别解析，不把不同歌曲的结果合并成一首；各行仍由用户选择。解析完成后每行默认选择首个候选；最高分候选与原值相同时保留`最佳&保留`。专辑先确定，日期和曲序再从该专辑中选择；没有候选则保留原值。点击顶栏✓后应用。

选择专辑后，日期、Disc、Disc总数、Track、Track总数只显示该专辑的候选。若源站明确给出曲序则使用；按列表推断曲序时，必须有完整列表、唯一稳定ID和目标ID。只在完整列表中所有碟号都有效且连续时推断碟片总数，不把未知碟号填成1。

点击`查看封面`先请求150px预览。下载和✓各自询问尺寸，默认1000，0表示向源站请求最大可用版本。源站可能不接受任意尺寸，程序只作有限回退，不把小图放大冒充原图。保存存当前已取得的图片字节，沿用文件名规则并加`-cover`；生成卡片的PNG／JPG压缩设置不作用于封面。

图片字节仍使用原CoverLoader的80MiB页面内缓存，离开歌曲信息页时清理。分享解析不另写磁盘图片缓存；用户确认使用的封面按现有活动封面流程保存。

## 外部输入与歌曲JSON

现有Android分享、打开方式和别名不变。显式JSON文件继续进入原替换确认流程。外部普通文本先尝试严格解析歌曲JSON对象：合法对象走替换确认；其余文本打开`来自音乐软件`并填入原文，不自动联网。

两个`编辑歌曲信息JSON`入口都支持普通对象和完整的JSON代码块：

````text
```json
{"title":"爱我别走","artist":"张震岳"}
```
````

确认时按现有规范化逻辑整理键名、字符串和有效标签，移除空值、布尔值、嵌套对象等无效值；不从解释性文字中随意截取花括号。`cover`是新增预留字符串字段，可填写网络URL或本地图片路径；仅保留数据，不访问链接，不读取本地文件，不替换当前封面。

AI页显示八项原有字段，提示词输出标准包含九项，额外的`album artist`可在JSON编辑器保存。生成提示词时使用AI页当前输入和其余现有JSON字段。AI页顶栏✓只返回；JSON编辑器里的确认才应用JSON。

## 网络和测试记录

请求限制到平台及图片域名，逐次验证跳转目标，有超时、响应体上限和有限重定向。旧接口的明文HTTP仅开放四个指定主机。官方同平台HTTP跳转优先升级HTTPS。不携带用户Cookie，不绕过地区或账号限制。

固定响应回放保留在`test/fixtures/share`：六平台历史响应来自用户实验包；QQ专辑列表因原录制缺少POST正文，测试中明确标为模拟。酷狗`dataFromSmarty`来自本次核对的官方桌面页。这些回放证明解析逻辑，不代表接口一直可用。

2026-11-01本环境联网结果：QQ、酷我、汽水取得标题、艺术家、专辑及曲序；酷狗新结构取得《惊鸿一面》、许嵩／黄龄、《不如吃茶去》、2014-08-23、5/9；网易云仅返回部分信息；波点MV返回中国大陆地区限制。接口、歌曲版权和地域会影响结果。
