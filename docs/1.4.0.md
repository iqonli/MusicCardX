# MusicCardX1.4.0

版本1.4.0+14，包名com.iqonli.musiccardx。沿用iqonli-1签名，ARM64版本号2014，x86_64版本号4014，可覆盖同签名旧版本。

## 在线搜索封面

输入页封面区域增加“在线搜索封面”。自动带入当前标题、艺术家、专辑；修改搜索框只用于本次检索，不回写歌曲信息。

- 搜索源：163、Apple、Apple网页。默认开启163和Apple，Apple网页可直接勾选。右上角地球按钮设置Apple地区，默认cn，支持两位地区代码（如us、jp）。搜索源、地区和尺寸都会自动保存并随配置导出。
- 候选为自适应网格，普通手机两列，窄屏一列、宽屏最多六列。卡片显示封面、标题、艺术家、专辑、来源、评分；大字体会增加卡片高度。按匹配分数排序，同来源同专辑的重复歌曲保留最高分候选，低分不直接排除。
- 预览封面尺寸默认150，下载封面尺寸默认1000，两者独立。输入0表示请求源端可获得的最大版本。尺寸按最长边限制，保留宽高比，不拉伸、不在本地放大小图；服务端提供更小的图片时显示实际尺寸。
- “最大”继承原工具的尝试策略：Apple依次尝试4000、3000、2000、1200及原地址，不能保证服务端提供原始上传文件；163请求不带缩略尺寸的原地址。正数尺寸会在响应超过指定边长时缩小。
- 点击候选进入大图页。右上角从左到右为下载、保存、✓，无底部“保存封面”“使用此封面”按钮。
- 下载立即按下载尺寸获取图片，完成后替换当前查看图片。保存只保存当前已加载版本：未下载大图时保存预览，下载后保存大图，不隐式下载。✓先按下载封面尺寸获取大图，成功后应用并返回；如果已经下载成功则直接使用该大图，不重复下载。下载失败保留当前页面，不应用预览图；不修改歌曲信息。
- 保存到设置中的图片目录，文件名按当前歌曲信息和既有标题格式规则生成，再在扩展名前追加`-cover`。沿用PNG/JPG压缩设置；首次保存未选择目录时仍需选择目录；重名追加时间戳。输入页原“保存封面”也统一使用这套命名。
- 大图页支持既有PhotoView缩放、平移和触摸停止惯性。显示实际宽高、当前图片大小，下载时有进度（缺少Content-Length时使用不确定进度）。下载失败保留原预览，可继续使用、保存或重试。

## 请求、匹配和资源管理

- 使用dart:io的HttpClient连接池，限制每主机连接数、连接超时和单次请求期限，支持取消。无WebView、.NET、FFmpeg或服务器依赖；Android正式包新增INTERNET权限。
- 163继承Legacy、EAPI、WEAPI回退及上一成功路线偏好；移植AES和RSA请求格式，使用PointyCastle4.0.0实现AES。Apple使用公开iTunes搜索；Apple网页从网页及JS读取访问令牌，再请求目录接口。
- Apple公开搜索全局预约请求间隔3100ms；来源会受接口变化、地区、限流和网络影响。所谓Apple网页源不保证“不限速”。
- 先搜标题、艺术家、专辑组合，分数不足时简化关键词。匹配使用Unicode归一化、编辑距离、词集合、艺术家拆分、版本标记差异和字段错位降分；移植原工具按缺失字段调整权重的逻辑。
- 各来源完成后逐步显示结果，一个源失败不挡住其他源。来源可单独重试，保留其他来源结果；新搜索或离开页面取消旧请求，旧结果不得覆盖新搜索。
- 缩略图按需加载，解码和下载最多两个并行；当前页面原始图片缓存上限12MiB，候选最多60项。退出页面释放缓存，不新增持久搜索图片目录。下载字节上限32MiB；解码前检查尺寸，拒绝超过3200万像素或单边16384的图片。大图显示另用最多2048像素宽的解码版本，保存和使用仍保留当前图片数据及实际尺寸。
- 在线图片用于当前封面时才写入受现有清理策略管理的covers目录。保存的用户图片不作为缓存清理。

## 配置覆盖检查及修复

详见[配置覆盖清单](CONFIGURATION.md)。文档中所有设置均在配置JSON内，涵盖图钉、显示字体、monet、图片格式和质量、保存目录和命名、全部渲染参数、各圆角独立参数、环境色、歌词、各文字样式和本次新增的在线搜索设置。

修复以前配置导入/切换总是强制保留当前图片目录的问题：配置明确提供目录时应用该值，旧配置未提供时才保留当前目录。切换配置后同步图钉状态、monet及显示字体。

字体管理器原来单独保存的来源模式、共享目录、预览文本和预览字号，现在导出时采集，导入/切换时恢复。字体索引、字体二进制、共享库授权和图片资源不嵌入JSON；跨设备需要另外导入字体或授权目录。字体预览页临时试选的字重不属于已保存设置。

本地配置库继续保留正在编辑的歌曲信息和当前封面，仅切换设置与排版；完整JSON导入可以包含歌曲信息和封面路径。无效字段继续通过类型、枚举和范围校验清理。旧版本缺少在线搜索与字体偏好字段时有默认值，不会阻止打开。

## 验证及限制

验证日志保存于docs/validation/1.4.0：完整Flutter测试、静态检查、ARM64/x86_64 release构建、包名/版本/联网权限/单活动检查和签名核验。仍使用iqonli-1证书。

构建环境下的联网检查：163返回30个候选并取得可识别缩略图；Apple在us区返回30个候选，取得150×150和1000×1000封面；Apple网页在cn区返回22个候选，取得137×150和916×1000封面。测试样例仅证明本次所用网络与查询可用，不保证所有地区和歌曲都有结果。cn区某次公开Apple查询返回0条，地区目录差异正常展示为空结果。

没有Android真机测试，安装后仍需验证手机网络、外部存储授权和真实候选交互。在线获取与图片使用授权属于不同事项，本次实现不附带第三方封面的额外使用许可。
