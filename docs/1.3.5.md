# MusicCardX 1.3.5

版本1.3.5+13，沿用iqonli-1签名。ARM64和x86_64独立安装包可覆盖同签名旧版。

## 修改

- 背景截取封面位置弹窗新增0—100滑动条，和数值框双向同步，保留小数输入和原校验。
- 封面增加椭圆圆角（横向、纵向半径）、二次曲线圆角（半径、曲线张力）、圆弧内凹角（半径）。继续使用同一弹窗，类型有图标、参数平铺，各类型独立保存，可导入导出。
- 全局等待改为横向进度条及阶段文字。文件写入（保存、分享/复制缓存）按字节显示百分比；渲染、PNG/JPG压缩和系统交接没有可靠进度回调，使用不确定进度。复用现有分享缓存时不执行重复写入。
- 输入页歌曲信息、歌词输入期间只保存草稿，不反复渲染。离开输入框、切换tab或直接导出时提交并触发渲染。正在完成的旧预览不会覆盖新输入状态。
- 设置“保存图片文件夹”下方新增“保存图片文件名称”。支持现有标题格式表达式，新增%seed%（融合模式有效，其他模式为空）。弹窗实时预览当前信息生成的文件名，包含导出格式后缀和非法文件名字符处理。
- 默认表达式：`MusicCardX-[%title%-][%artist%-][%album%-][%seed%]`。方括号对应字段有值才显示，符合用户指定的各信息后带短横线格式。非融合模式可能以短横线结尾。名称过长按UTF-8字节数限制，避免超过Android目录项限制；重名仍追加时间戳。
- 分享、复制向接收方提供设置后的显示文件名，内部缓存继续按内容摘要复用，避免因改名重复存图。缓存写入先使用临时文件，完成后改名。

## 保守优化

- 对当前封面、取色算法、自定义环境色状态缓存一个环境色计算结果；参数或封面变化立即失效，失败允许重试。不写入磁盘，不累计历史封面的像素数据。
- 自动彩虹色仅保留当前封面和采样边长的一个计算结果，参数变化重算。
- 同次渲染的相同字体规格只解析一次。
- 预览按文档快照计算，避免异步读取到编辑一半的配置。
- 导出复用有效预览的现有行为、bicubic采样和背景生成算法保持。
