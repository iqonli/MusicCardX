# MusicCardX1.3.2

版本1.3.2+7，包名com.iqonli.musiccardx，沿用iqonli-1签名，可覆盖安装上一版本。

## 选点

- 内部色点由25.5dp缩为17.85dp，即1.3.1的0.7倍。
- 外圈半径为色点半径的2倍，直径35.7dp。外圈只绘制1dp、70%不透明度的描边，内部透明；圆内仍可拖动取色。
- 选取顺序1—5显示在色点圆心，没有标签背景，文字使用当前取色的RGB反色，拖动取色时同步刷新。
- 选满5个后显示确认按钮，同时将开始连续选取5个改为重新连续选取5个。
- 再次点击已选色点会取消该项，后面的编号自动前移。取消后不足5个时隐藏确认按钮，补选的点排在最后。

## 圆角弹窗

- 封面圆角只打开一个弹窗。七种类型直接平铺为带图标的选项，不再使用类型下拉菜单。
- 各类型参数直接显示数字输入框，不再打开第二层数值弹窗。
- 独立四角为两行两列输入框，名称为↖、↗、↙、↘。
- 保留各类型独立参数和实时预览，切换类型后再切回来会保留已填写的值。输入错误或越界时就地提示，不写入无效值。

## 控件和颜色

- 输入页按钮采用标准触控尺寸，文字按钮最小88×48dp，列表式操作高度至少48dp，字号继续为13。保留封面区第一行选择图片、第二行保存封面与移除封面的布局，无按钮图标。
- 底部三个纯文字tab恢复56dp正常高度，系统底部安全区另行保留。
- 字体预览只保留纯白底、纯黑字，继续保留字重调整和自定义预览文本的保存。
- 修复自动黑白色按钮使用空标题导致开头多出8dp间隔的问题。固定标题使用普通文字颜色，锁黑色/锁白色状态使用主题强调色，与其他参数按钮一致。
- 自动黑白色仍按原顺序切换自动、锁黑色、锁白色；渲染目标色仍为#121212和#FAFAFA。

## 大图惯性

大图平移松手后使用Flutter的ClampingScrollSimulation，采用默认摩擦系数0.015，让位移随松手速度变化。移除PhotoView原来的固定推进100dp动画，接触图片或开始新手势会停止旧惯性，保留缩放、双击和图片边界限制。

本地补丁基于photo_view0.15.0，保留MIT版权。详见third_party/photo_view/MCX-PATCHES.md。采用Flutter与Android滚动物理对齐的实现，并不宣称与各厂商图库的全部手势行为相同。

## 外部打开复用

- 删除两个分别寻址的活动别名，将图片、歌曲JSON/文本及音频的分享/打开过滤器统一放到MainActivity，保留各入口提示文案。
- MainActivity使用singleTask和documentLaunchMode=never，恢复包名默认任务归属，外部文件打开时复用现有主活动。
- 关闭Flutter自动文件URI深链接，由已有的导入确认和队列处理文件，避免自动增加文件路由。
- 保留上一版的顺序接收队列，取消或失败后继续下一份，不覆盖待确认内容。

## 验证

47项Flutter测试通过，静态检查无问题。另对实际编辑器中的圆角弹窗做了界面检查并生成截图。测试覆盖色点尺寸、描边透明度、居中反色编号、取消后重排及重新选取、各类圆角直接输入、按钮与底栏高度、黑白按钮切换、字体预览、Android惯性轨迹及触碰停止，以及原有渲染、字体和导入回归。

arm64-v8a和x86_64的Release APK均构建并验证签名。直接核对最终APK清单：一个活动、无活动别名、singleTask、documentLaunchMode=never、文件自动深链接关闭。记录见docs/validation/1.3.2。

未进行Android真机运行测试，MIUI上的最近任务及外部打开行为仍需实际设备复测。标题格式、选点工作图等范围仍以1.3.1说明为准。
