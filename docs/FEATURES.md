# 1.1.0 更新

字体管理与选择已重写为 Dart；所有字体页面使用 Flutter。输入／工作台两个入口，图钉和大图预览已修复，详见 1.1.0.md。下表保留初版映射供追溯。

# 原版功能映射

| MusicCard 功能 | MusicCardX Android |
|---|---|
| foobar 选中／焦点曲目、标签、内嵌封面 | 改为手动字段、歌词及系统图片选择器 |
| 八个文字元素及整列编辑 | 样式页独立编辑＋批量修改 |
| 字号、粗体、斜体、字体 | 独立设置；系统列表及原生字体管理器 |
| HEX、自动黑白、rainbow 表达式、不透明度 | 保留 |
| 模糊发光、模糊不透明度 | 独立文字层与滤镜 |
| 空字间距与 0 的不同语义 | 整段排版与逐字排版分别实现 |
| 动态卡片宽度、无封面重排 | 保留 |
| 非方封面裁剪／原比例、圆角／圆形、阴影 | 保留；Flutter 绘制 |
| 融合／墨点／采点／模糊／纯色 | 五种独立实现；融合维持原有风格原则 |
| 种子输入、复制、刷新 | 样式页及预览工具栏 |
| 模糊 0–500、封面截取位置 | 保留；多轮强度映射至 Flutter 模糊 |
| 平均色相、自定义目标色、五个环境色 | 保留 |
| 歌词启用、宽度、上／下间距、行距、横／纵对齐 | 保留 |
| 歌词渐变分隔线及所有颜色、不透明度、间距 | 保留 |
| 卡片／歌词独立简繁转换 | 原版词典，Dart 前缀树及分词／转换链 |
| 预览、尺寸／耗时、休眠 | 保留；预览 1x、支持缩放 |
| 1–4x、自定义 0.1–10x PNG | 保留；单张像素限制详见 README |
| 保存、复制图片 | 系统保存器、Android image/png 剪贴板 URI；新增分享 |
| 界面字体与输出字体分离 | 保留 |
| 字体列表 | Android 系统字体列表＋ezCD 导入字体管理／选择器 |
| JSON 配置导入、导出、选择、恢复默认 | 系统文件选择器＋本地配置库 |
| 切歌歌词确认 | 手动输入版没有自动切歌；输入页提供清空歌曲和歌词 |
| foobar Title Formatting | 常用表达式子集，未知函数报错；完整引擎留待桥接版 |
| GDI+ 0–5 文字模式 | 保留配置编号；单色抗锯齿开关映射，平台专有拟合不等价 |
| GDI+ 剪贴板边缘像素修补 | 新版直接生成 PNG，不移植宿主专用缺陷修补 |
| 编辑／重载 SMP 脚本、foobar 目录 | Android 无对应宿主；源码在独立工程中维护 |

未接入 bridge、播放器、媒体通知或在线搜歌；所有输入均为手动。
