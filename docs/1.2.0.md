# MusicCardX 1.2.0

包名保持 com.iqonli.musiccardx，versionCode 3，沿用 iqonli-1 签名，可覆盖安装 1.0.0 / 1.1.0。同名图片保存时自动添加时间后缀，不覆盖已有图片。导入或切换样式配置保留当前保存图片文件夹。

## 工作台与输入

工作台按原 MusicCard.js 的功能顺序分行，按钮根据文案与当前值决定宽度，不再统一等分。每个分区独立横向滑动；表格列根据表头和内容测宽，长文本与长字体名设最大宽度并省略显示。点击表头直接批量修改对应列，点击第一列进入该元素的详细样式；普通单元格直接修改。

已有的“模糊强度”“封面圆角”“封面阴影不透明度”“不规则封面”“歌词排版”“容器右侧与封面距离”等文案沿用 JS；移动端特有操作使用相应中文。二选一、三选一直接点击循环切换，较多选项使用选择列表。布尔值显示开、关，开加粗。歌词与分隔线区域的展开、折叠同时控制启用、停用，保留折叠前参数。输入页使用普通纵向表单，新增独立歌词输入框。

底栏为输入、工作台、设置。字体、配置与关于移到设置，删除旧快捷工具栏。常规控件字号统一为 13；页面标题和实际图片、字体预览按各自用途显示。

## 颜色与绘制

颜色区域依次为自定义环境颜色、自定义彩虹色。环境色开启后显示五个带 HEX 的色块，背景为颜色本身、文字为 RGB 反色；点击打开颜色选择器。彩虹色开启后显示五个无文字窄色块，选中项有高亮，目标来自当前环境调色板。移除独立“自定义目标色”入口，旧配置的 hex 目标迁移到第一个环境色。

颜色选择器包含饱和度/明度色板、色相条、色样、RGB、HSL、HEX，支持触摸和数值输入。文字及分隔线仍支持自动黑白色和原有 r% / rainbow% 表达式。

自动黑白色保持原版加权灰度公式与 #121212 / #FAFAFA，默认阈值 0.5，可在颜色区域修改。墨点与采点的绘制实现对调。仅保留 Flutter 抗锯齿文字绘制，导入旧渲染编号统一迁移为抗锯齿，不再提供单色、网格拟合等菜单。

随机新种子为八位十进制，保留前导零；手动输入的已有种子不强制改写。新种子按钮使用刷新图标。

## 预览与图片

预览与输出共用倍率和渲染器，显示实际输出像素。预览栏左侧仅显示“宽×高 耗时ms”，右侧为图钉，无放大按钮。点击图片进入独立大图页。图钉默认打开：预览固定在滚动区域外；关闭后随内容滚动。设置页不显示预览。

大图页支持双指缩放、以点击位置为中心的双击放大、再次双击还原、缩放后平移、适应屏幕及原始大小。平移限制在图片边界，小于屏幕的轴居中；单击隐藏或显示查看控件。缩放控制器由页面持有并释放，旋转时重新适配。

顶栏仅保留复制图片、分享、保存图片。设置中增加保存图片文件夹；首次保存可选择目录，随后直接写入 PNG 并通知媒体库扫描。封面优先调用 Android 图片选择器，较旧系统使用系统图片内容选择入口。

## 字体与文件

字体名称规则与 ezCD 对齐：名称表依次优先 Windows 英文、Unicode、Mac 英文等记录，不再随界面语言优先中文。名称与家族键使用 Unicode 规范化。字重识别参考子家族、PostScript、全名、文件名、OS/2 和可变轴，包含 Light、SemiBold、W3 等命名规则及中文样式名。

字体按家族分组，选择标准字重代表面；组内按字重、斜体、子家族、文件名排序。点击家族名称进入标准字体预览，右侧小箭头单独展开家族。支持家族批选、单面选择、全选、筛选、删除。预览含 12、18、24、36、48、60、72、80、88、96 与自定义字号，预览文字和字号会保存，字体信息可查看和复制。

正文使用选中的真实字重，粗体匹配同家族 700 字重，斜体优先匹配对应字面；可变字体显式设置 wght / ital / slnt。每个字面单独注册，避免整个家族被 Flutter 固定请求 400/700 而错选；对错误 OS/2 样式元数据仅在运行时副本中修正，不改原文件和哈希。TTC 拆面及修改后校验和重算。相同哈希、相同面索引复用已加载字体，减少重复注册。

字体来源仍二选一：X 导入字体或依赖于 ezCD。共享目录只读，保持 v1 清单、路径、状态与哈希校验，更新失败保留上一份可用快照。旧 SAF 目录仍可读取，新选择使用应用内文件管理器。旧本地索引自动重新提取名称与字重，保持原字体 ID。

字体导入、配置导入/导出、共享库目录与图片目录选择使用 Flutter 文件管理器，支持路径跳转、目录浏览、多文件选择、新建目录。Android 11 及以上首次使用需在系统设置授予文件访问；Android 宿主仅处理权限、图片选择和通用文件、分享、剪贴板接口，没有 Kotlin 字体管理或 Typeface 逻辑。

## 验证与边界

16 项自动测试覆盖原 OpenCC、手动字段、配置、五种背景 PNG、种子、输出保护、ezCD 协议/更新回退、TTC、ezCD 字重样本和运行时校验和、本地与 ezCD 字体相同渲染、颜色选择器、导航/表格/图钉/大图视口；另完成静态分析及 APK 构建、签名检查。没有完成 Android 真机交互测试，安装后由用户验证文件授权、系统选图、保存和剪贴板接收。

Flutter 与原 GDI+ 的字形栅格化及滤镜不会逐像素一致，融合种子保持相近算法风格，不承诺与原版相同种子得到相同图片。单张输出仍限制为 3200 万像素、单边 16384 像素，超出会提示减小输出。
