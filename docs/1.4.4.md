# MusicCardX1.4.4

在线搜索歌曲信息改为传统爬爬、AI外包、来自音乐软件三个tab。传统搜索和原有气泡流保留；AI页生成可编辑、可复制的元数据补全提示词；音乐软件页可解析网易云、QQ、酷狗、酷我、波点、汽水分享链接，逐项选择并应用信息。

两个歌曲JSON编辑入口支持完整的JSON代码块，粘贴后格式化，确认后标准化。外部普通文本先判断是否为歌曲JSON，其他文本填入分享解析页；显式JSON文件仍走原替换确认流程。新增预留`cover`字符串字段，仅保存URL或本地路径，暂不加载。

分享链接封面先请求150px预览，下载和使用前询问尺寸，默认1000，0为最大。图片保存沿用原始字节和`-cover`文件名规则。

工程版本1.4.4+20。ARM64包versionCode2020，x86_64包versionCode4020，沿用iqonli-1签名。未在Android真机上运行本次版本，接口限制和联网记录见[MUSIC_SHARE.md](MUSIC_SHARE.md)。

本次修订不推进版本号：搜索页点击输入框以外的位置立即失焦；重复外部分享先回主页再打开解析页，避免页面层叠；生成提示词后把操作行滚动至顶部，使用说明移到提示词框上方；解析说明改为正文内超链接；分享解析完成后默认勾选各项首个候选，`最佳&保留`维持保留，日期和曲序跟随选中的专辑。

AI提示词更新为用户给定的轻度／重度校正模板，替换已有信息占位符，保留九字段与JSON代码块输出要求。

再次修订：输入页入口改为“在线搜索”，新增九字段禁用管理，禁用项显示“已禁用”且不可编辑，数据在JSON、音频和在线结果导入后统一过滤；新增同时清空歌曲信息、封面与歌词的按钮。AI页JSON编辑移到生成／复制右侧，模板去除空白行。弹窗操作文案统一为“确定”。版本及versionCode保持不变。
