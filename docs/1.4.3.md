# MusicCardX1.4.3

版本1.4.3+18，沿用iqonli-1签名。

歌曲信息搜索改为八行独立横向气泡流：固定项目名称、保留原值、去重候选。默认各行保留原值，右上角✓一次应用选择；选择“未提供”会移除该字段。最高分候选与原文完全相同时合并到“最佳&保留”。搜索中禁用应用，重新搜索恢复默认保留。

每个字段按修剪首尾空白后的实际文本去重。同来源同歌曲ID只计一次。评分为Q=0.85×最高原组合分+0.15×平均原组合分，S=Q+(100-Q)×0.3×(1-exp(-(n-1)/2))。单次出现保留原分，重复出现的加分随次数递减，最大为剩余分数的30%。分数降序，相同分数按文本排序。色块随分数加深，保留项固定使用100分颜色；选中状态另用勾选和边框表示。

两个搜索页右上角均提供小地球，支持输入全球ISO两字母区域代号，自动转小写并随配置保存。该地区用于Apple服务；163和QQ的接口不提供全球目录切换。地区不受源站支持时可能无结果，不承诺每个代码都有内容。

数学测试覆盖高质量重复胜过相近单次、低质量重复不能挤掉高质量、重复记录不重复计数及分数边界。未进行Android真机测试。

## 同版本修订（内部构建号+19）

八行及第一列名称共用一个横向滚动区域，保留纵向页面滚动。两个搜索页面统一使用TextButton搜索／停止按钮及FilterChip搜索源按钮。日期、Disc／总数、Track／总数仅从当前所选专辑的候选中去重评分；专辑按实际名称匹配，不混合不同专辑的数据。改变专辑选择后，这五项恢复“保留”，避免应用已经不可见的旧专辑候选。各搜索源的状态与候选数量显示在八行下方的页面底部。
