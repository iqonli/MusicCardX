## 介绍

MusicCardX是[MusicCard](https://github.com/iqonli/MusicCard)的Flutter移植版。目前先做Android，独立运行，不需要foobar2000。

输入歌曲信息，选一张封面，再调成自己喜欢的样式，就可以保存、复制或分享图片。歌曲信息可以手动填，也可以从音频文件读取、粘贴JSON，或者在线搜索。程序不会修改原音频文件的Tag。

目前包含：

- 融合、墨点、采点、模糊、纯色五种背景
- 封面圆角、独立四角、超椭圆等形状，以及裁剪、阴影
- 八个独立的文字元素，字号、字重、字体、颜色、透明度、光晕和字间距分别设置
- 歌词排版、对齐、行距及渐变分隔线
- 封面取环境色、自定义环境色、选点取色和自动黑白色
- 融合背景种子输入、复制及种子博览会
- 字体导入、家族与字重分组、可变字体，以及只读接入ezCD字体库
- 样式配置保存、复制、重命名及JSON导入导出
- 在线搜索封面、在线搜索歌曲信息
- PNG／JPG输出、输出倍率、文件夹和文件名规则设置

程序使用ChatGPT／Codex辅助开发。README也经过辅助整理。

## 重要提示

1. 最低支持Android8.0。一般手机请选择`arm64-v8a`安装包；`x86_64`主要供相应架构设备和模拟器使用。
2. 同签名版本可以覆盖安装。自行编译的Debug包不能直接覆盖正式签名包。
3. 卡片编辑和渲染可以离线使用，在线搜索需要联网。搜索接口可能因地区、网络或源站调整暂时不可用。
4. **配置JSON不包含封面和字体文件。** 换设备时请另行保存这些文件；卸载前也请先导出需要的配置和图片。
5. **在线搜到的信息要自己核对。** 同一首歌可能有原版、现场版、重录版和不同地区的专辑发行日期，分数高也不代表一定正确。
6. Flutter与原版GDI+的字体和模糊效果存在差异。同种子不保证与原版生成完全相同的背景。

## 安装与使用

从[Releases](https://github.com/iqonli/MusicCardX/releases)下载APK并安装。

1. 打开`输入`，填写标题、艺术家、专辑等信息，选择封面。也可以从音频文件读取。
2. 打开`工作台`调整背景、颜色、文字和歌词排版。点击表头可以批量修改一列，点击第一列可以修改对应项目。
3. 在`设置`管理字体、配置、保存目录、图片压缩和文件名。
4. 查看预览，满意后分享、复制或保存图片。

应用自动保存当前编辑状态。在输入框中连续编辑时，离开输入框后再刷新预览。预览跟随输出倍率；图钉开启时固定显示，关闭后随页面滚动。预览支持双指缩放和平移，单击打开大图。

### 在线搜索封面

在`输入`中点击`在线搜索封面`，填写标题、艺术家和专辑，选择搜索源后搜索。

预览封面尺寸默认150，下载封面尺寸默认1000，输入0表示请求源站最大尺寸。实际返回尺寸以源站为准。低于设定分数的候选不会自动加载图片，可以手动加载。

点击候选查看大图，右上角从左到右为：

- 下载：下载设定尺寸的大图。
- 保存：保存当前图片。还没下载大图就保存小图，已经下载则保存大图。
- ✓：先下载大图，成功后用作当前封面；下载失败不会用小图代替。

保存封面沿用文件名规则，并在末尾加`-cover`。**封面拿到什么就保存什么，保留原始图片字节，不受图片压缩设置影响。** 压缩设置只作用于应用生成的卡片。

### 在线搜索歌曲信息

在`输入`的歌曲信息区域点击`在线搜索歌曲信息`。标题和艺术家必填，专辑选填。

支持163、Apple、Apple不限速和QQ音乐。搜索结果按标题、艺术家、专辑、完整日期、Disc及总数、Track及总数拆成八行共用横向滚动的气泡流，分别去重和评分。每行独立选择，默认保留原填写项。选定专辑后，日期、Disc和Track的候选仅显示该专辑的数据；切换专辑会将这些项目恢复为保留。

右上角小地球可填写全球两字母区域代号，✓应用当前八行的选择。未提供的字段显示`未提供`，主动选择该候选会清空该项。保留气泡固定使用100分背景；排名第一恰好等于原值时合并为`最佳&保留`。此操作只更新歌曲信息，不替换封面和歌词，不写回音频文件。

### 字体

在`设置`中打开字体管理器，选择`导入字体`或`依赖于ezCD`，两种方式二选一。

本地导入支持TTF、OTF、TTC、OTC和ZIP字体包，按家族、字重分组。可变字体支持相应轴的连续调整，普通字体按实际存在的字重选择。应用界面字体与生图字体分开设置。

ezCD模式读取用户授权目录中的`ezcd-fonts.json`，校验并缓存字体，不会修改ezCD的外部存储库。更换目录或设备后可能需要重新授权。接入说明见[ezCD字体共享文档](docs/ezCD-font-sharing-v1.md)。

字体导入使用应用内文件管理器；封面选择使用Android图片选择器。选不到文件时，请检查目录访问权限。

### 文字、颜色和文件名

文字可以直接填，也可以写标题格式化表达式，例如：

```text
%title%
[%datey%]
[$num(%tracknumber%,2)[ / %totaltracks%]]
```

兼容常用的`$if`、`$if2`、`$if3`、`$num`、`$len`、`$and`、`$or`、`$not`、`$upper`、`$lower`、`$trim`、`$replace`和条件括号等语法；尚未实现完整的foobar2000标题格式化引擎。未知函数会提示错误。

颜色支持六位HEX、`black`、`white`和彩虹混色表达式。HEX项目使用普通输入框，可通过`插入`选择颜色；自定义环境色和彩虹色使用颜色选择器。卡片文字和歌词可分别进行简繁转换。

文件名默认规则：

```text
MusicCardX-[%title%-][%artist%-][%album%-][%seed%]
```

`%seed%`仅在融合模式有值。文件名弹窗会用当前歌曲信息实时预览，非法文件名字符会被清理，同名文件不会直接覆盖。

## 一些使用上的细节

**好看的背景要自己刷。** 融合背景根据环境色和种子生成，可以在种子博览会中挑选。同一X版本、封面、配置和种子可以复现结果，换封面或取色算法也会改变背景。

**字间距留空与填0不同。** 留空使用字体原生整段排版；填写数值后使用逐字绘制，0也会走逐字绘制，因此连字和字偶距可能变化。

**图片宽度不是固定的。** 它会随文字、封面比例和歌词容器改变。单张输出建议不超过1亿像素、单边最长32768像素。超过任一数值时会弹窗警告，可以取消或继续生成；继续生成可能占用大量内存。

**搜索缓存会清理。** 在线封面搜索页的图片字节缓存上限为80MiB，离开搜索页后清空。这个数值不是整个APP的内存上限。已使用的封面、导入的字体、配置和用户保存的图片会保留。

## 自行编译

当前验证工具链：Flutter3.47.9、Dart3.13.7、JDK21、AndroidSDK36、BuildTools36.0.0、NDK28.2.13676358。依赖版本由`pubspec.lock`固定。

在工程目录执行：

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

AndroidStudio或VSCode均可编辑。`android/local.properties`填写本机SDK路径，不要提交到仓库。

Release构建需要自己的签名：将密钥放到`signing/`，新建`android/signing.properties`：

```properties
storeFile=../signing/your-key.jks
storePassword=your-store-password
keyAlias=your-alias
keyPassword=your-key-password
```

```sh
flutter build apk --release --target-platform android-arm64,android-x64 --split-per-abi
```

**不要公开私钥、密码或签名配置。** 自行使用其他密钥签名的APK不能覆盖官方版本。
