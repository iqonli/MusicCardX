# MusicCardX1.4.2

版本1.4.2+17，继续使用iqonli-1签名。

- 输入页“编辑歌曲信息JSON”上一行增加“在线搜索歌曲信息”。标题和艺术家必填，专辑选填。支持163、Apple、Apple不限速、QQ音乐独立启停，Apple可选择CN／US地区。搜索源与地区纳入配置保存、导入和恢复默认样式时保留项。
- 候选按匹配分数排序，逐行对比原标题、艺术家、专辑、完整日期、Disc／总数和Track／总数，搜索值加粗。保留各来源同专辑的不同歌曲候选。来源未提供的字段明确标注，应用时保留原值和额外Tag，不改封面、歌词或音频文件。应用前二次确认。
- 163按专辑ID和精确歌曲ID补全日期、曲序、已提供的曲目总数。Apple保留返回的日期、Disc及Track总数。QQ优先使用已验证的移动搜索入口，歌曲详情补全日期和曲序，零基Disc编号转为一基。未知总数不推测。
- 网络请求使用现有dart:io HttpClient，沿用超时、响应上限和取消机制。元数据页不下载候选封面；每源最多12个候选，每源最多2个详情请求并行。退出或重新搜索取消旧任务，单源失败不清除其他源结果。
- 使用用户提供的SVG图标。保留原始SVG，文字转为路径，生成各密度普通图标和带安全留白的自适应图标。无需运行时字体。
- 重写根目录README，包含安装、使用、在线搜索、字体、配置限制、图片原图保存行为、编译和签名说明，保留在源码中。查阅iqonli公开仓库的所有可获取README；无法据此判断作者是否使用AI，因此不声称文档来源为非AI。

在线接口会受网络、地区和上游调整影响，日期与版本信息仍需用户核对。未进行Android真机测试。
