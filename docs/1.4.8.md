# 1.4.8

- “来自音乐软件”新增平台别名与ID提取，平台名可在ID前后，允许空格、制表符及换行。
- 支持无协议网址、完整分享文案、song?id=数字及其他参数形式中的ID。
- 无平台的数字ID尝试网易云、QQ、酷狗、酷我、波点、汽水。最多处理10个输入，每批最多3个查询，保留所有成功的平台结果。
- 同平台同ID去重；完整网址以自身域名为准，不把URL内部数字拆成额外ID。
- 支持用户列出的所有别名，不区分大小写；额外保留kugou拼写。
- QQ歌曲mid、酷狗hash和纯数字歌曲编号属于不同标识。酷狗分享口令不等同于歌曲编号；尝试解析不保证平台存在相应歌曲。
- 不同平台可能使用相同数字ID，请核对候选歌曲后再应用。元数据读取不涉及下载歌曲音频。

示例（每条也可单独粘贴）：

```text
wyy music.163.com/#/song?id=2617714044
163 2617714044
网易 song?id=2617714044
2617714044 网易云
2617714044
```

最后一条会尝试全部平台。多条结果按平台、ID去重，不保证最终仅出现一首歌曲。

验证：426项Flutter测试通过，静态分析无问题；尚未完成Android真机测试。

## 平台别名

| 平台 | 别名（不区分大小写） |
|---|---|
| 网易云 | 网易云、网易、wyy、wy、163、163cn、网易云音乐 |
| QQ | QQ、企鹅、QQ音乐 |
| 酷我 | 酷我、kw、kuwo、酷我音乐 |
| 酷狗 | 酷狗、酷狗音乐、酷狗概念版、酷狗音乐概念版、kugo、kugou、kg |
| 波点 | 波点、波点音乐、bd、bodian |
| 汽水 | 汽水、汽水音乐 |

非数字别名还可与数字直接相连，如 `网易2617714044`、`2617714044wyy`。`163`作为平台别名需要分隔符；单独的`163`仍作为ID尝试全部平台。QQ还支持平台名加14位歌曲mid，酷狗支持32位hash。
