# MusicCardX1.5.0_beta2

四种新背景使用上传的v7 C++公式重写，通过Dart FFI调用C++17动态库，后台isolate负责发起计算。融合classic等旧背景、字体和整卡合成继续由Flutter渲染。

## 一致性

保留X命名空间的种子规则、五色来源、20项实验参数范围、660px工作网格和原有缩放/模糊路径。为匹配归档Dart版，C++改用double，立方根使用同样的pow(x,1/3)，关闭fast-math及浮点乘加融合。按行多线程计算，每个像素独立写入固定位置。封面预处理和beta1背景缓存保留。

历史Dart逐像素实现和参考测试保存在archive/dart-backgrounds-beta1，生产入口lib/seed_backgrounds.dart仅负责参数、内存和FFI调用。lib/cover_preparation.dart保留封面缩放及预模糊。

上一轮Linux宿主对照：48组完整RGBA、24组整卡PNG与beta1逐字节一致；36组原生输出的单/多线程一致。覆盖种子、彩色/灰色/黑白环境色、横竖比例、有无封面、缓存命中和失效及0.2×/0.5×/1×/2×输出。临时环境重置后，test/native_beta2_test.dart已再次通过48组RGBA和24组整卡对照。

以上不是所有设备和所有输入的证明；不同系统数学库可能产生浮点末位差异。手机仍需验证。

## 模块构建

模块路径third_party/mcx_background，仅一份C++源码。

- Android：ffiPlugin，externalNativeBuild，CMake3.22.1，NDK28.2.13676358；构建arm64-v8a和x86_64。
- Linux：cmake -S third_party/mcx_background -B native-build -DCMAKE_BUILD_TYPE=Release，再cmake --build native-build。宿主库可用MCX_BACKGROUND_LIBRARY绝对路径覆盖，执行flutter test test/native_beta2_test.dart。
- Windows：同一CMake项目支持MSVC，/O2 /fp:strict；插件windows目录随应用打包mcx_background.dll。已用LLVM-MinGW在Linux交叉编译Windows x64 DLL，并检查mcx_alloc/mcx_free/mcx_render导出；静态链接C++运行库，仅依赖Windows系统DLL。未运行Windows程序，未验证Windows输出一致性；MSVC构建文件已提供但未实测。
- iOS/macOS：提供podspec和C++包装编译单元，libc++、C++17及链接符号保留；FFI使用DynamicLibrary.process。需macOS/Xcode/CocoaPods环境验证。

完整应用当前只有Android runner，模块可跨平台构建不代表字体、文件、分享等Android功能已移植到Windows和Apple平台。

## 性能

上一轮Linux AOT测试，1200×400逻辑尺寸、660px网格，封面预处理已完成；四个新种子取中间值：流光约12ms、soft37ms、hard55ms、雾化56ms。这是背景计算，不是手机整卡计时，也不保证手机低于200ms。

## FFI

mcx_alloc/mcx_free/mcx_render采用C ABI，Dart调用方分配输出，finally释放所有原生内存。原生校验尺寸和容量，以错误码返回异常，异常不跨FFI边界。默认最多8线程，支持threads=1检查确定性。UTF-8种子通过显式长度传递，支持Unicode和内嵌空字符。
